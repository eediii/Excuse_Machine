# Bahanematik (The Excuse Generator) 🙅‍♂️🎲

**Bahanematik** is a fun, "Party Edition" web application that helps you generate creative excuses instantly. It fetches a random "No" reason from an API, automatically translates it into Turkish, and presents it in a colorful, responsive interface suitable for TVs, PCs, and Mobile devices.

![Project Screenshot](./screenshot.png)
## 🌟 Features

* **Random Excuse Generation:** Fetches witty and creative excuses on demand.
* **Auto-Translation:** Automatically translates excuses from English to Turkish using the MyMemory API.
* **Responsive Design:**
    * 📱 **Mobile:** Clean and compact.
    * 💻 **Desktop:** centered card layout.
    * 📺 **TV Mode:** Large typography and optimized spacing for 4K/Large screens.
* **Party UI:** Animated gradient backgrounds, rounded aesthetics, and the friendly "Nunito" font.

## 🚀 How to Run (From Scratch)

You don't need to install any complex software like Python or Node.js to run this project. It is built with pure HTML, CSS, and JavaScript.

### Prerequisites
* A modern web browser (Chrome, Firefox, Edge, Safari).
* An internet connection (required for the APIs to work).

### Installation Steps

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/YOUR-USERNAME/bahanematik.git](https://github.com/YOUR-USERNAME/bahanematik.git)
    ```
    *(Or simply download the `index.html` file)*

2.  **Open the file:**
    * Navigate to the folder where you downloaded the file.
    * Double-click on `index.html`.
    * That's it! The app should open in your default browser.
